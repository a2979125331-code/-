# 单机三国杀 · 四人身份局

从旧版四个文件重新实现的纯前端小游戏：1名玩家与3名电脑，从发身份、选武将、起手摸牌、回合行动、响应、濒死救援直到胜负结算。无需账号、联网服务或构建依赖。

## 运行

直接打开 `index.html` 即可（普通脚本，无本地模块限制）。也可安装 Node.js 22 或更高版本后执行 `npm start`，访问 http://127.0.0.1:8000 。

## 玩法

- 先随机发放主公、忠臣、反贼、内奸各一个，再选将。玩家身份自己可见，主公公开，其余身份阵亡或结算后公开。
- 玩家从8名武将中任选，其余3名随机且不重复；每人4张起手牌。主公先行，四人局不增加主公体力。
- 摸牌（通常2张）→出牌→弃牌至当前体力值→下一位存活角色。空牌堆会洗回弃牌堆，结算中的牌不会参与重洗。
- 选中一张手牌或自己的已装备牌后，在操作区点出牌方式或目标。仁德、制衡允许多选。闪、杀的被动响应、技能询问、救援和弃牌均使用操作区按钮。
- 杀通常每个出牌阶段限一次，武器决定攻击范围、正负马修正距离；阵亡者不计入座位距离。响应杀、决斗或群体锦囊时可以放弃。
- 体力不大于0时按当前回合座次依次求桃，救回后继续结算。无人救援则阵亡并公开身份。
- 主公存活且反贼、内奸均阵亡：主公与忠臣获胜（忠臣阵亡也可获胜）。主公死亡且仅内奸存活：内奸胜；其他主公死亡情况：反贼胜。
- 未结束的对局中，击杀反贼摸3张牌；主公击杀忠臣弃全部手牌和装备。游戏结束立即停止后续奖励和行动。
- 玩家阵亡后自动观战。重新开局会取消旧局计时任务。

## 八名武将

沿用旧仓库名单，按经典标准版补齐技能（不采用界限突破版）。主公技仅在身份为主公时生效，具体效果在选将界面显示。

|武将|体力|技能|
|---|---:|---|
|刘备|4|仁德：任意交给他人手牌，累计两张时回复1点体力，每回合仅回复一次；激将（主公技）：使用或响应杀时请求其他蜀势力角色提供，主动失败后本阶段不能再次主动激将|
|关羽|4|武圣：红色手牌或装备当杀使用或响应|
|张飞|4|咆哮：出牌阶段杀不限次数|
|曹操|4|奸雄：可获得仍在结算区的伤害牌；护驾（主公技）：需要闪时请求其他魏势力角色提供|
|夏侯惇|4|刚烈：可判定，非红桃时来源弃两张手牌或受1点伤害|
|孙权|4|制衡：出牌阶段限一次，弃任意张手牌或装备并摸等量牌；救援（主公技）：濒死时其他吴势力角色用桃救援，额外回复1体力|
|周瑜|3|英姿：摸牌阶段多摸一张；反间：阶段限一次，目标猜花色并获得随机手牌，猜错受1伤害|
|华佗|3|急救：回合外红色手牌或装备当桃救援；青囊：阶段限一次，弃一张手牌使受伤角色回复1体力|

## 精简范围

这是基础玩法版本，不是完整官方标准包复刻。目前仍不含其他武器、酒和延时锦囊。无需判定的回合阶段直接略过。

82张自定义牌堆：杀24、闪15、桃8、决斗3、过河拆桥4、顺手牵羊4、无中生有4、南蛮入侵2、万箭齐发1、无懈可击5、装备12。花色/点数为固定生成的自定义分布。拆桥/顺手可选择随机暗置手牌或指定公开装备。群体牌按座次结算，中途分出胜负即停止。

AI使用自身身份、公开主公身份及对主公的攻击记录判断敌友，不读取其他角色隐藏身份或手牌内容。支持新增技能、装备和无懈决策，优先拆除防具与武器；孙权先使用可进攻的牌，再制衡剩余弱牌和多余防御牌。策略仍较基础，不保证最优决策。

## 装备与无懈可击

装备有武器、防具、进攻马、防御马四个栏位；同栏新牌会弃置旧牌。装备不计入手牌上限，阵亡及主公误杀忠臣时一并弃置。自己的装备显示为“已装备”，可点选用于制衡、武圣等允许使用装备的技能；仁德、青囊仍只能使用手牌。

|装备|数量|效果|
|---|---:|---|
|诸葛连弩|2|范围1，出牌阶段杀不限次数|
|青釭剑|1|范围2，杀无视目标防具|
|八卦阵|2|需要闪时可翻牌判定，红色视为出闪；失败仍可出手牌闪|
|仁王盾|1|黑色杀无效|
|赤兔、大宛、紫骍|各1|到其他角色距离-1，同类不能叠加|
|绝影、的卢、爪黄飞电|各1|其他角色到你的距离+1，同类不能叠加|

无懈可击在每张锦囊对一名目标生效前询问，可放弃。每次出无懈重新询问所有存活角色；奇数张抵消效果、偶数张恢复效果。群体锦囊逐个目标分别询问，不会因一张无懈跳过整张群体牌。无懈不能抵消杀、装备或武将技能。反制链内的牌留在结算区，结束后才进入弃牌堆。

激将、护驾按主公之后的座次询问同势力角色，可以拒绝；失败后仍可使用自己的响应牌。反间直接点目标；青囊先选一张手牌再选受伤目标。主公技是否可用由真实身份决定，不能由选将自动获得。

规则参考：[官方标准曹操/护驾说明](https://www.sanguosha.com/news/20161101_5213_3118)、[官方标准刘备介绍](https://www.sanguosha.com.tw/newsinfo_906.html)、[装备规则集](https://gltjk.com/sanguosha/rules/card/equipment.html)。本版牌堆数量仍为自定义配置，并非完整108张标准牌堆。

## 验证与结构

运行 `npm test`。包含发身份、选将、非法操作、响应、距离、救援、奖励惩罚、三方胜利、弃牌及八将技能测试；150组固定种子完整对局验证终局与82张牌（含装备和结算区）的唯一归属。

- `engine.js`：独立规则引擎，生成器暂停在玩家决策点。
- `app.js`：渲染与电脑行动调度。
- `index.html` / `styles.css`：中文界面、键盘焦点与窄屏布局。
- `tests/engine.test.cjs` / `tests/expansion.test.cjs`：35项 Node.js 测试，无第三方依赖。
- `server.cjs`：可选的本地静态服务器。

旧版源码保留在主分支历史中；此次重做通过独立分支的 PR 审阅，未合并前不改变主分支。
