# 单机三国杀 · 四人身份局

纯前端、无需后端的单机三国杀基础实现。当前版本目标不是复刻完整官方规则库，而是先让一局 4 人身份局从发身份、选武将、摸牌、出牌、AI 行动到胜负判定完整跑通。

## 当前内容

### 模式
- 4 人身份局
- 身份构成：1 主公、1 忠臣、1 反贼、1 内奸
- 主公身份公开，其余 AI 身份阵亡后公开
- 玩家身份开局后可见
- 主公额外 +1 体力上限

### 8 名基础武将
- 刘备：仁德
- 关羽：武圣
- 张飞：咆哮
- 曹操：奸雄
- 夏侯惇：刚烈
- 孙权：制衡
- 周瑜：英姿
- 华佗：急救

技能均为适合本单机基础版的简化实现，重点保证流程可玩和规则闭环。

### 基础牌
基本牌：
- 杀
- 闪
- 桃
- 酒

锦囊牌：
- 决斗
- 过河拆桥
- 顺手牵羊
- 无中生有
- 南蛮入侵
- 万箭齐发

装备牌：
- 青龙偃月刀：攻击范围视为 2
- 八卦阵：需要闪时 50% 概率自动视为出闪

### 已实现流程
1. 选择武将
2. 随机发放身份
3. AI 随机获得其余武将
4. 每人起手 4 张牌
5. 从主公开始行动
6. 摸牌阶段
7. 出牌阶段
8. 弃牌阶段
9. 回合结束
10. AI 自动行动
11. 濒死桃/华佗急救
12. 阵亡与身份公开
13. 击杀反贼奖励 3 张牌
14. 主公误杀忠臣弃置全部手牌与装备
15. 主公阵营、反贼、内奸胜负判定

## AI

当前 AI 为规则驱动型，能执行：
- 受伤时优先使用桃
- 无中生有
- 装备武器/防具
- 孙权制衡
- 刘备仁德
- 酒 + 杀
- 杀
- 决斗
- 过河拆桥
- 顺手牵羊
- 南蛮入侵
- 万箭齐发
- 基于身份阵营选择敌友目标

内奸 AI 当前采用简化敌对逻辑，后续可继续增加控场和残局策略。

## 运行方式

直接打开 `index.html` 即可。

如果浏览器限制本地 ES Module，可在仓库根目录运行：

```bash
python -m http.server 8000
```

然后访问：

```text
http://localhost:8000/
```
